# Задание 6.6 — Самое длинное слово в текстовом файле

В данном репозитории представлено решение дополнительного задания 6.6 по курсу Python.

## Условие задачи
Необходимо объявить функцию `longest_word()`, которая получает на вход
имя текстового файла в виде строки и возвращает самое длинное слово из этого файла.

Если слов максимальной длины несколько, функция должна возвращать первое
вхождение такого слова.

Функцию вызывать в скрипте не требуется.

## Пример
Пусть файл `pushkin.txt` содержит следующий текст:

Мороз и солнце; день чудесный!  
Еще ты дремлешь, друг прелестный —  
Пора, красавица, проснись:

Вызов функции:

longest_word('pushkin.txt')

Результат:

'прелестный'

## Реализация
Решение находится в файле `task6_6.py`.

Функция:
- `longest_word(filename)` — читает текст из файла, удаляет знаки пунктуации,
  разбивает текст на слова и возвращает самое длинное слово.

Функция не выводит данные на экран и предназначена для проверки и тестирования.
