# Задание 6.6. Самое длинное слово в текстовом файле

Данный репозиторий содержит решение дополнительного задания 6.6 по курсу Python.

## Описание задания
Необходимо объявить функцию `longest_word`, которая принимает на вход
имя текстового файла в виде строки и возвращает самое длинное слово,
содержащееся в этом файле.

Если в тексте присутствует несколько слов одинаковой максимальной длины,
функция должна возвращать первое из них.

Вызов функции в скрипте не требуется.

## Пример работы
Пусть файл `pushkin.txt` содержит следующий текст:

Мороз и солнце; день чудесный!  
Еще ты дремлешь, друг прелестный —  
Пора, красавица, проснись:

Результат вызова функции:

longest_word('pushkin.txt')

Вернёт:

'прелестный'

## Реализация
Решение реализовано в файле `task6_6.py`.

Функция `longest_word(filename)`:
- читает содержимое текстового файла;
- удаляет знаки пунктуации;
- разбивает текст на слова;
- возвращает самое длинное слово.

Функция не выводит данные на экран и предназначена для автоматической проверки.
