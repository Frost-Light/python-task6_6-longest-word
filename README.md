# Задание 6.6 — Python

В репозитории представлено решение дополнительного задания 6.6 по курсу Python.

## Описание задачи
Реализована функция `longest_word`, которая принимает имя текстового файла
и возвращает самое длинное слово из этого файла.
Если слов с одинаковой максимальной длиной несколько, возвращается первое.
Пунктуация при обработке текста игнорируется.

## Файл с решением
- task6_6.py

## Функция
- longest_word(filename): возвращает самое длинное слово из текстового файла

## Пример
Вызов функции:

longest_word('pushkin.txt')

Результат:
'прелестный'

Функция не вызывается в коде и предназначена для тестирования.
